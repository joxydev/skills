# Промпт для карусели Instagram

Прочитайте [профиль бренда](../brand/brand-profile.md), [стиль](../brand/visual-style-guide.md), [правила изделия](../brand/product-rules.md) и [регламент сохранности](product_preservation_rules.md). Нужны настоящие фотографии каждого ракурса и подтверждённая карточка изделия. Не выдумывайте новые виды предмета.

## Входные данные

```text
Продукт и подтверждённые характеристики: [ ]
Реальные фотографии / порядок / права: [ ]
Цель карусели и аудитория: [ ]
Одна идея и ценность для читателя: [ ]
Подтверждённые факты о материале, работе, цене, комплекте: [ ]
Неподтверждённые факты: [ ]
Тип: товарная галерея / история / демонстрация деталей / подарок / другое [ ]
Желаемое действие: [ ]
```

## Копировать в запрос

> Подготовь 2–3 разные концепции карусели Instagram о `[изделие]` для `[аудитория]`, каждая с одной понятной идеей и ценностью `[ценность]`. Используй только предоставленные реальные фото и подтверждённые сведения. Для каждой концепции покажи таблицу: номер кадра, задача, какое исходное фото или видео использовать, очень короткий текст на кадре при необходимости, композиция и alt-описание по реальному изображению. Первый кадр должен давать понятную причину листать; следующие показывают реальные детали или факты; завершение даёт итог и один CTA `[действие]`. Для товарной галереи допустимы фото без текста и без отдельного CTA-слайда. Число кадров выбирай по материалу, не дублируй ради объёма. Дополнительно напиши подпись, которая дополняет кадры и содержит один CTA. Выдели лучший вариант и отдельно назови отсутствующие сведения. Визуальный стиль: натуральный, тёплый, чистый и фотореалистичный; само изделие не изменять. Не придумывай отзывы, материал, цену, сроки, вид с другой стороны, этапы работы или особые свойства.

## Проверка

Первый кадр читается с телефона, каждый слайд действительно добавляет информацию; шрифт и контраст в едином стиле; не закрыты резьба и важные детали. Тексты вычитаны и добавлены отдельно от генерации, чтобы избежать вымышленных надписей. Сверьте каждый кадр с исходным фото на 100%; если применялся ИИ к фону — проверьте требования к маркировке.
