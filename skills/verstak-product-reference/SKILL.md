# Эталонная предметная сцена verstakmd

Сначала прочитать ../../brand/brand-profile.md, ../../brand/product-rules.md и ../../brand/visual-style-guide.md, затем references/reference-inventory.md. Для подписи прочитать ../../brand/caption-style-guide.md. Эти инструкции относятся к конкретной лавке; не навязывать их другим брендам.

## Обязательная композиция

Икона стоит вертикально основанием на столе. Нарды и шахматная доска лежат на столе. Не выводить положение изделия только из фронтального вида камеры. Для другого ракурса нужен соответствующий реальный исходник. Не синтезировать скрытые стороны.

Тёмная коричневая деревянная столешница, тёплая матовая серо-бежевая стена, мягкий рассеянный свет, натуральные тени, один центральный предмет, свободные поля, без отвлекающего реквизита. Сохранять цвет каждого изделия: светло-тёмное дерево иконы Матроны, красноватое покрытие второй иконы, медово-чёрная доска и тёмные створки нард — разные предметы, а не единый фильтр.

Не добавлять графические надписи поверх товара. Надписи и орнамент самого изделия неприкосновенны. Сохранять фактуру, геометрию, лица, руки, края и реальные дефекты. Генерировать только окружение вне защищённого предмета; сравнивать оригинал и итог на 100%. При сомнении использовать оригинальную фотографию.

Выдать 2–3 варианта в рамках этой сцены. Проверить опору на стол, положение, масштаб, свет, отсутствие перерисовки и читаемость деталей. Не обещать сохранность по одному промпту.

Изображения видны в диалоге, но их бинарные файлы пока не извлечены в рабочую среду. Инвентарь не заменяет оригиналы при обработке конкретного товара. После получения файлов хранить утверждённые эталоны в brand/references/, указать имя, контрольную сумму и связь с описанием; не помещать их в игнорируемые products/.
